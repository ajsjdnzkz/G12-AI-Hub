G12 AI Hub — New Mansoura University
=======================================

Files:
- index.html — the website
- MAT114_Lecture_01.pdf — MAT114 Lecture 1
- faculty-logo.jpg — Faculty logo

To publish for classmates with GitHub Pages:
1. Create/sign in to a GitHub account.
2. Create a NEW public repository named: G12-AI-Hub
3. Upload index.html, MAT114_Lecture_01.pdf, and faculty-logo.jpg.
4. Open repository Settings -> Pages.
5. Under Build and deployment choose "Deploy from a branch".
6. Choose branch "main" and folder "/ (root)", then Save.
7. After deployment, the site will be available at:
   https://YOUR-GITHUB-USERNAME.github.io/G12-AI-Hub/

Your classmates do NOT need GitHub accounts; they only need the link and Chrome.
